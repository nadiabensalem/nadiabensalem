**Plateforme web de gestion universitaire** — projet de fin d'études réalisé en stage chez BeeDigital (févr. – juin 2026)

- Plateforme multi-rôles avec **5 tableaux de bord** : Super Admin, Admin, Enseignant, Étudiant et Parent
- Gestion des **emplois du temps, absences et notes**, avec contrôle d'accès par rôle (RBAC)
- Authentification sécurisée **JWT + Spring Security**, API REST documentée avec **Swagger**
- **Assistant IA** d'orientation universitaire basé sur **LLaMA 3.3 70B** via l'API Groq
- Architecture 3-tiers **Angular 18 / Spring Boot / MySQL**, développement en sprints **Scrum**
